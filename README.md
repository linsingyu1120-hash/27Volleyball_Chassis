# 27Volleyball_Chassis 万向轮底盘F4代码

## 模块简介

代码基于26年暑假校内赛底盘代码，将H7代码进行移植优化。底盘轮组为万向轮，通过大z驱动电机转动。底盘可以通过蓝牙调试器进行移动。电机整定时需要使用老的zdrive上位机。
移植过程中，考虑到日后维护方便，保留了原有的imu，vofa功能。蓝牙模块没有采用f4模板代码，是在原h7代码下进行修改的。

## 文件说明

- `APL/` - 用户自定义扩展功能，在此目录下新建子目录并添加功能模块
  - `APL/Tasks` - 任务函数实现，底盘相关任务为 Chassis_Task
  - `APL/Chassis` - 单轮和四轮全向底盘的运动学解算 
- `Core/` - cubemx生成的源码，禁止添加新的文件
- `DOCS/` - 模板工程相关文档
- `FML/` - 功能模块库，包含了常用的零碎功能模块，按需补充
  - `FML/algorithm` - 数学算法，来源于27RC的h7模板代码
  - `FML/bluetooth` - 蓝牙模块，内涵底盘的蓝牙协议
  - `FML/imu` - imu模块，目前暂没有进行维护
  - `FML/vofa` - vofa模块，目前咱没有进行维护
- `HDL/` - 板级外设驱动，包含灯和蜂鸣
- `IRQ/` - 中断服务函数，包含了中断回调函数重定义
  - `IRQ/uart_irqhandler` - 蓝牙的收发通过u1，imu的接收通过u2的RX，vofa的发送通过u2的TX
- `Motor/` - 电机驱动，目前仅添加了z和dji
